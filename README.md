# PrimeLab Diagnostics Centre — 100 Websites Challenge #07

Accurate Reports, Delivered Fast. Multi-page diagnostic laboratory website (HTML/CSS/JS) with real photos in `images/`, a searchable 26-test catalogue with PKR prices, home sample-collection booking (PL-XXXXXX references, WhatsApp), and a report-status tracker.

Part of the **100 Websites Challenge** by Abdullah Mahmood Official — one new business website every day.

## Pages

- `index.html` → Home (hero, popular tests, home collection, report lookup)
- `tests.html` → Full test catalogue — search & category filter, sample type, report time
- `home-collection.html` → Home sample collection — how it works, areas, booking
- `reports.html` → Report-status check by booking reference
- `packages.html` → Health checkup packages
- `about.html` → Lab introduction, equipment & quality process
- `contact.html` → Address, phone/WhatsApp, hours, form

## Tech

Plain HTML, CSS and JavaScript — shared `css/style.css` and `js/` scripts, no build step. Just open `index.html` or serve the folder with any static server.
